## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Vikashan10/my-portfolio.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

No dependency installation or build step is required.

## Deployment

The portfolio can be deployed as a static website on [Vercel](https://vercel.com/):

1. Push the project to GitHub.
2. In Vercel, select **Add New → Project**.
3. Import the GitHub repository.
4. Choose **Other** as the framework if prompted; use the repository root as the project directory.
5. Deploy. Updates pushed to the connected production branch can trigger new deployments.
